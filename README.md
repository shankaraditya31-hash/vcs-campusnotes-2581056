# CampusNotes

CampusNotes is a simple project created as part of the
Version Control Systems (CSE25303) assignment.

## Purpose
To understand and practice Git and GitHub workflows.

## Topics
- Git Basics
- Remote Repositories
- Branching
- Pull Requests
- Version Control

## Learning Goals

- Understand Git workflows.
- Practice branching and merging.
- Learn GitHub collaboration.
- Understand remote repositories.
